Hvor mye kan jeg nå?

1. `hent_oversikt` for snittkarakter, temaer hørt og fagord som glipper.
2. `hent_laringslop` for gapet mellom gjennomgått og hørt.
3. `list_fagord` med status `ny` og `usikker` hvis noe skiller seg ut.

Gi meg **ett** tall med én setnings begrunnelse, og **ett** konkret neste steg.

Ikke pynt på det. Snittet er av siste karakter per tema, så det stiger bare når jeg faktisk blir bedre. Er gapet mellom gjennomgått og hørt stort, si det rett ut.
