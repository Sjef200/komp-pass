Kapittelarbeid. $ARGUMENTS

Følg skillen `kapittelarbeid`:

1. Bekreft faget. Ikke anta.
2. Kall `list_kapitler` og `hent_kapittel` for kapittelet jeg er i.
3. Er jeg i lesefasen: ta imot notater og bilder, lagre med `lagre_kapittelnotat` / `legg_ved_bilde`. Ikke oppsummer boka.
4. Er jeg ved øving: lim inn bokas kontrollspørsmål og oppgaver med `legg_inn_oving`. Ett om gangen.
5. Hør med `neste_oving`. Still nøyaktig det spørsmålet. Vent.
6. Glipper det: nøste opp (forklar X, hva er Y, hvorfor), så tilbake til bokspørsmålet.
7. Logg med `logg_oving` og `logg_horing` (`ovingId`, `kapittelId`, promptId `kapittelarbeid`).
